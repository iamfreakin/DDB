# 테스트 전략

## 계층

- 단위 테스트: 도메인 규칙, 데이터 변환, 검증 함수
- 통합 테스트: API, 저장소, AI 공급자 어댑터
- 계약 테스트: 공급자 응답과 내부 모델 변환
- API 계약 테스트: 상태 코드, 응답 스키마, 공통 오류 형식
- E2E 테스트: 가게 입력부터 결과 저장까지
- AI 평가: 사실성, 관련성, 브랜드 일관성, 안전성

## 원칙

- 외부 AI API는 기본 테스트에서 모의 응답을 사용한다.
- 실제 API 평가는 별도 수동 또는 제한된 평가 작업으로 수행한다.
- 모든 Must 요구사항은 하나 이상의 테스트와 연결한다.
- OpenAPI 스키마와 `request_response_schemas.md`의 예제가 일치해야 한다.
