# 서비스 사용방법

- 상태: Review
- 대상: 발표자, 시연자, 일반 사용자
- 서비스명: AI 소상공인 콘텐츠 제작실

## 1. 실행 방법

프로젝트 루트에서 백엔드를 먼저 실행한다.

```powershell
.\scripts\run_backend.cmd
```

다른 터미널을 열고 프론트엔드를 실행한다.

```powershell
.\scripts\run_frontend.cmd
```

브라우저에서 다음 주소로 접속한다.

```text
http://localhost:3000
```

## 2. API 키 사용 방식

API 키가 없어도 Mock 생성기로 전체 흐름을 시연할 수 있다.

실제 OpenAI API를 사용하려면 브랜드 작업실 왼쪽의 `AI 설정`을 열고 API 키를
입력한다.

입력 항목은 다음과 같다.

| 항목 | 설명 |
|---|---|
| OpenAI API 키 | 사용자가 직접 입력하는 개인 API 키 |
| 모델 | 텍스트 생성 모델. 기본값은 `gpt-5-mini` |
| 이미지 모델 | 이미지 생성 모델. 기본값은 `gpt-image-2` |

API 키는 현재 브라우저 탭의 `sessionStorage`에만 저장된다. 코드, 데이터베이스,
로그 파일에는 저장하지 않는다.

## 3. 전체 사용 흐름

```text
홈 화면
-> 새 브랜드 만들기
-> 가게 정보 입력
-> 브랜드 분석 생성
-> 분석 수정 및 승인
-> 캠페인 생성
-> 4주 전략 생성
-> 게시물 8개 생성
-> 문구 변형 선택
-> 포스터 브리프 생성
-> 포스터 이미지 생성 및 승인
-> 캘린더 생성 및 최신화
-> 보고서/CSV 내보내기
```

## 4. 새 브랜드 만들기

홈 화면에서 `새 브랜드` 또는 시작 버튼을 누른다.

입력할 정보는 다음과 같다.

- 가게 이름
- 업종
- 대표 상품
- 주요 고객
- 가게 강점
- 원하는 분위기
- 지역
- 가격대
- 기존 홍보 문구
- 피하고 싶은 표현

입력을 완료하면 브랜드 작업실로 이동한다.

## 5. 브랜드 분석

작업실의 `브랜드 분석` 화면에서 `새 분석 생성` 버튼을 누른다.

시스템은 입력한 가게 정보를 바탕으로 다음 내용을 생성한다.

- 브랜드 요약
- 핵심 고객
- 고객 니즈
- 가치 제안
- 차별점
- 브랜드 보이스
- 추천 키워드
- 피해야 할 표현
- 부족한 정보

생성 결과는 초안이므로 사용자가 확인한 뒤 승인한다. 승인된 브랜드 분석은 캠페인
전략 생성의 기준이 된다.

## 6. 캠페인 전략

`캠페인 전략` 화면에서 캠페인을 만든다.

입력할 정보는 다음과 같다.

- 캠페인 이름
- 홍보 목표
- 시작일
- 강조 상품
- 반드시 포함할 사실 정보

캠페인을 만든 뒤 전략 생성 버튼을 누르면 4주 홍보 전략이 생성된다.

전략에는 다음 정보가 포함된다.

- 핵심 메시지
- 주차별 목표
- 콘텐츠 기둥
- 게시물 주제 8개
- 주의할 점

## 7. 콘텐츠 생성과 문구 선택

`콘텐츠` 화면에서 캠페인을 선택하고 게시물 8개를 생성한다.

각 게시물에는 다음 정보가 포함된다.

- 주차
- 콘텐츠 유형
- 주제
- 핵심 메시지
- 문구 변형
- CTA
- 해시태그
- 이미지 콘셉트

게시물별로 마음에 드는 문구 변형을 선택한다. 선택된 문구는 이후 포스터와 캘린더에
반영된다.

## 8. 포스터 브리프 생성

게시물 상세 화면에서 `포스터 브리프` 버튼을 누른다.

포스터 브리프에는 다음 정보가 포함된다.

- 제목
- 보조 문구
- 비주얼 분위기
- 색상
- 레이아웃 지시
- 이미지 프롬프트
- 제외 요소
- 포스터 비율

사용자는 브리프 내용을 직접 수정할 수 있다.

## 9. 포스터 이미지 생성

포스터 스튜디오에서 `이미지 생성` 버튼을 누른다.

이미지 생성 전에는 비용 확인 안내가 표시된다. API 키가 입력되어 있으면 실제 이미지
API를 호출하고, API 키가 없으면 Mock 이미지가 생성된다.

생성 후 사용자는 다음 작업을 할 수 있다.

- 포스터 미리보기
- 다시 생성
- PNG 다운로드
- 최종 승인
- 이전 생성 이력 확인

이 프로젝트는 이미지 모델이 한글을 틀릴 수 있다는 점을 고려해, AI가 배경 이미지만
만들고 앱이 정확한 한글 제목과 보조 문구를 합성한다.

## 10. 캘린더 생성과 최신화

`캘린더` 화면에서 `캘린더 생성` 버튼을 누르면 4주 일정에 게시물이 자동 배치된다.

캘린더에는 다음 정보가 표시된다.

- 게시 날짜
- 주차
- 게시물 주제
- 선택된 문구
- CTA
- 승인 포스터 여부
- 콘텐츠 상태

게시물 상태나 승인 포스터가 바뀐 경우 `최신화` 버튼을 누르면 캘린더가 최신 상태로
갱신된다. 캘린더 조회 시에도 콘텐츠 상태는 자동 동기화된다.

## 11. 내보내기

서비스는 두 가지 내보내기를 제공한다.

| 버튼 | 결과 |
|---|---|
| 브랜드 보고서 | 승인된 브랜드 분석을 Markdown 파일로 저장 |
| CSV 다운로드 | 콘텐츠 캘린더를 CSV 파일로 저장 |

캘린더 CSV에는 날짜, 채널, 유형, 주제, 선택 문구, 핵심 메시지, 상태, 승인 포스터
여부가 포함된다.

## 12. 시연 순서 추천

발표나 수업 시연에서는 다음 순서를 추천한다.

1. 홈 화면에서 서비스 목적을 설명한다.
2. 새 브랜드를 만든다.
3. 브랜드 분석을 생성하고 승인한다.
4. 캠페인을 만들고 4주 전략을 생성한다.
5. 게시물 8개를 생성한다.
6. 첫 게시물의 문구 변형을 선택한다.
7. 포스터 브리프를 생성하고 일부 문구를 수정한다.
8. 이미지 생성 버튼으로 포스터를 만든다.
9. 포스터를 승인한다.
10. 캘린더를 만들고 최신화한다.
11. 브랜드 보고서와 CSV 다운로드를 보여준다.

API 키가 없을 때도 Mock 생성 결과로 같은 순서를 시연할 수 있다.

## 13. 주의사항

- AI 생성 결과는 초안이므로 반드시 사용자가 검토한다.
- 실제 API 키를 사용할 경우 이미지 생성 비용이 발생할 수 있다.
- API 키는 코드에 직접 넣지 않는다.
- 포스터에 들어가는 한글 문구는 앱이 합성하므로 브리프의 제목과 보조 문구를 먼저
  확인한다.
- 생성 요청이 오래 걸릴 수 있으므로 같은 버튼을 반복해서 누르지 않는다.
- 캘린더를 발표 자료로 사용하기 전 `최신화` 버튼을 한 번 누르는 것이 좋다.
