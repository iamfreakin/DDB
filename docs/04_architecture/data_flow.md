# 데이터 흐름

```text
가게 입력
-> 입력 검증
-> 브랜드 프로필 버전 저장
-> 브랜드 분석 요청
-> 구조화된 분석 결과 저장
-> 사용자 수정 및 승인
-> 캠페인 설정 저장
-> 전략 생성 요청
-> 게시물 8개와 초기 변형 생성
-> 포스터 브리프 생성
-> 사용자 수정본을 별도 변형으로 저장
-> 사용할 변형 선택
-> 캘린더 배치
```

각 생성 결과에는 입력 프로필 버전, 프롬프트 버전, 모델 설정, 생성 시각을
메타데이터로 연결한다.

프로필이 변경되면 기존 결과를 삭제하지 않고 오래됨 상태를 계산해 사용자에게
표시한다.
