# 콘텐츠 생성 명세

- 상태: Review

## MVP 지원 콘텐츠

- Instagram 피드 문구

콘텐츠 유형은 상품 소개, 정보형, 공간·관계형, 프로모션형으로 구분한다.
블로그, 문자, 카카오채널은 후속 범위다.

## 생성 옵션

- 목적
- 채널: MVP에서는 `instagram_feed` 고정
- 길이
- 문체
- CTA 유형
- 해시태그 사용 여부
- 이모지 사용 여부
- 생성 개수: 게시물당 1~3개

## 결과 구조

- 제목 또는 첫 문장
- 본문
- CTA
- 해시태그
- 이미지 콘셉트
- 사용한 핵심 메시지
- 검수 경고

## 출력 제약

- 캠페인 일괄 생성은 게시물 슬롯 8개를 만든다.
- 해시태그는 기본 5~10개다.
- 가격, 기간, 혜택, 효능은 캠페인의 `required_facts`에 있는 값만 사용한다.
- 각 결과는 구조화 출력 검증을 통과해야 저장한다.
- 사용자 편집은 AI 결과를 덮어쓰지 않고 새 `user_edit` 변형으로 저장한다.
