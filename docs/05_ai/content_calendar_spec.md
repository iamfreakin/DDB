# 콘텐츠 캘린더 명세

- 상태: Review

## 입력

- 캠페인 기간
- 주당 게시 횟수
- 사용할 채널: MVP에서는 Instagram 피드
- 주요 행사 및 휴무일
- 생성 또는 저장된 콘텐츠

## 출력 필드

- 게시 예정일
- 채널
- 콘텐츠 유형
- 주제
- 핵심 메시지
- 연결된 콘텐츠 ID
- 상태: `idea`, `draft`, `approved`, `published`, `on_hold`

## 배치 원칙

- 동일한 메시지의 과도한 반복을 피한다.
- 정보형, 상품형, 관계형 콘텐츠를 적절히 섞는다.
- 실제 기념일이나 시즌 정보 사용 시 날짜를 검증한다.
- 기본값은 4주 동안 주 2회, 총 8개 게시물이다.
- 모든 게시일은 캠페인 시작일과 종료일 사이여야 한다.
- 한 콘텐츠는 캘린더 항목 하나에만 연결한다.
