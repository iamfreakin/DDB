# 브랜드 분석 명세

- 상태: Review

## 입력

- 가게명과 업종
- 대표 상품 또는 서비스
- 지역
- 주요 고객
- 가격대
- 가게 분위기
- 차별점
- 피하고 싶은 표현
- 기존 홍보 문구

## 출력

- 한 문장 브랜드 정의
- 핵심 고객군
- 고객의 주요 필요
- 핵심 가치 제안
- 차별화 요소
- 브랜드 보이스
- 추천 키워드
- 피해야 할 표현
- 정보 부족 항목

## 출력 제약

- 브랜드 보이스는 정확히 3개다.
- 배열 항목은 중복 없이 간결하게 작성한다.
- 입력에서 확인할 수 없는 사실은 정보 부족 항목으로 보낸다.
- 출력 필드명은 `request_response_schemas.md`의 브랜드 분석 응답과 일치한다.
