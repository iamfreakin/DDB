# 프롬프트 관리 정책

- 프롬프트는 코드 문자열에 흩어놓지 않고 별도 템플릿으로 관리한다.
- 모든 프롬프트에 버전을 부여한다.
- 사용자 입력과 시스템 지시를 명확히 분리한다.
- 출력은 가능한 한 JSON Schema 등 구조화 형식을 사용한다.
- 가게 정보에 없는 사실을 만들지 않도록 명시한다.
- 생성 목적, 채널, 브랜드 보이스, 금지 표현을 입력 컨텍스트에 포함한다.

## 공통 출력 원칙

- 결과와 근거를 구분한다.
- 불확실한 정보는 추정하지 않는다.
- 해시태그, CTA, 이모지 사용 여부는 설정으로 제어한다.
