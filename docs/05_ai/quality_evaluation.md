# 생성 품질 평가 기준

| 항목 | 질문 |
|---|---|
| 사실성 | 입력에 없는 가격, 효능, 일정 등을 만들지 않았는가 |
| 관련성 | 선택한 목표와 상품에 직접 관련되는가 |
| 브랜드 일관성 | 정의된 보이스와 키워드를 따르는가 |
| 채널 적합성 | 채널의 길이와 표현 방식에 맞는가 |
| 실행 가능성 | 사용자가 약간의 수정으로 게시할 수 있는가 |
| 다양성 | 여러 결과가 단순한 단어 치환에 그치지 않는가 |
| 안전성 | 차별, 과장, 오해 유발, 권리 침해 위험이 없는가 |

평가는 규칙 기반 검사, LLM 평가, 사람 평가를 조합한다.
