# 이미지 및 포스터 생성 명세

- 상태: Review
- MVP는 브리프 수정과 실제 이미지 생성을 분리하고, 생성 버튼을 누른 경우에만
  외부 API를 호출한다.

## 입력

- 브랜드 프로필
- 캠페인 목적
- 상품 정보
- 포스터 비율
- 스타일
- 포함할 문구
- 제외할 요소

## 출력

- 이미지 생성 프롬프트
- 네거티브 프롬프트 또는 제외 조건
- 제목과 보조 문구
- 레이아웃 설명
- 색상 및 분위기 제안
- API 생성 결과 URL 또는 파일 참조
- 생성 이력, 초안·승인·대체 상태

## 주의

이미지 안의 긴 한글 문구는 깨질 수 있으므로 배경 이미지 생성과 텍스트 합성을
분리한다. 이미지 공급자는 글자와 로고가 없는 배경을 생성하고, 애플리케이션이
정확한 한글 제목과 보조 문구를 합성한다.

## 공급자와 실패 처리

- `ImageGenerationProvider` 인터페이스로 Mock과 OpenAI 공급자를 교체한다.
- API 키가 없으면 로컬 Mock 이미지를 생성해 전체 흐름을 검증할 수 있다.
- API 키는 요청 헤더로만 전달하며 DB, 파일, 로그에 저장하지 않는다.
- 외부 API 실패·시간 초과·사용량 제한 시 브리프를 유지하고 재시도를 제공한다.
- OpenAI 기본 이미지 모델은 `gpt-image-2`, 품질은 빠른 시연을 위한 `low`다.

## 저장과 승인

- DB에는 생성 이미지 파일의 상대 경로와 공급자·모델·프롬프트·크기만 저장한다.
- 배경 원본과 한글 합성본을 분리해 저장한다.
- 새 생성 결과는 `draft`, 승인 결과는 `approved`, 이전 승인본은
  `superseded` 상태가 된다.
