# 이미지 및 포스터 생성 명세

- 상태: Draft
- MVP에서는 실제 이미지보다 생성용 프롬프트와 레이아웃 지시를 우선한다.

## 입력

- 브랜드 프로필
- 캠페인 목적
- 상품 정보
- 포스터 비율
- 스타일
- 포함할 문구
- 제외할 요소

## 출력

- 이미지 생성 프롬프트
- 네거티브 프롬프트 또는 제외 조건
- 제목과 보조 문구
- 레이아웃 설명
- 색상 및 분위기 제안
- API 생성 결과 URL 또는 파일 참조

## 주의

이미지 안의 긴 한글 문구는 깨질 수 있으므로 배경 이미지 생성과 텍스트 합성을
분리하는 방식을 우선 검토한다.
