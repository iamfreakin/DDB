# 생성 메타데이터

- 상태: Review

각 생성 실행은 다음 정보를 저장하는 것을 원칙으로 한다.

- 생성 실행 ID
- 생성 유형
- 참조한 브랜드 프로필 버전
- 캠페인 ID
- 프롬프트 이름과 버전
- 공급자와 모델
- 생성 설정
- 시작 및 완료 시각
- 성공 또는 실패 상태
- 사용자 수정 여부
- 토큰 또는 비용 정보가 제공되는 경우 해당 값

## 저장하지 않는 항목

- 조합이 완료된 원문 프롬프트
- API 키와 인증 헤더
- 공급자의 전체 원본 응답
- 사용자가 입력하지 않은 개인정보

원문 대신 프롬프트 템플릿 이름, 버전, 해시와 입력 엔터티 ID를 저장한다. 디버깅에
필요한 공급자 응답은 민감정보를 제거한 뒤 개발 환경에서만 제한적으로 기록한다.

## 생성 유형

- `brand_analysis`
- `campaign_strategy`
- `content_batch`
- `content_variant`
- `poster_brief`
- `calendar_plan`
- `image_generation`

## 실패 기록

실패한 실행도 삭제하지 않고 상태, 내부 오류 코드, 사용자 입력을 포함하지 않은
안전한 오류 메시지, 시작·종료 시각을 저장한다.
