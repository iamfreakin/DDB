# AI Coding Agent 과업 지시서

## 공통 지침

1. `AGENTS.md`와 관련 문서를 먼저 읽는다.
2. 한 번에 하나의 구현 Step만 수행한다.
3. 구현 전에 변경 파일과 검증 방법을 제시한다.
4. 외부 API는 인터페이스 뒤에 격리한다.
5. 완료 후 테스트 결과와 남은 TBD를 기록한다.

## Step별 지시 형식

```text
목표:
참조 문서:
수정 범위:
입력과 출력:
예외 처리:
완료 조건:
테스트 방법:
금지 사항:
```

실제 개발을 시작할 때 `implementation_plan.md`의 각 Step을 이 형식으로 확장한다.
