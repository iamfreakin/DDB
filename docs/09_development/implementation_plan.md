# 구현 계획

- 상태: Draft

## Step 1. 프로젝트 기반

- 폴더 구조와 설정
- 데이터 모델
- 기본 FastAPI 및 Streamlit 연결
- 완료 조건: 상태 확인 API와 기본 화면이 동작한다.

## Step 2. 브랜드 프로필

- 입력 폼, 검증, 저장
- 브랜드 분석 생성
- 완료 조건: 프로필과 분석 결과를 저장하고 다시 조회한다.

## Step 3. 전략과 콘텐츠

- 캠페인 설정
- 홍보 전략 및 SNS 콘텐츠 생성
- 편집, 저장, 변형 생성

## Step 4. 캘린더와 비교

- 캘린더 생성 및 편집
- 저장 결과 조회와 비교
- Markdown 및 CSV 내보내기

## Step 5. 이미지 생성 확장

- 포스터 프롬프트 생성
- 이미지 공급자 어댑터
- 결과 저장과 오류 처리

## Step 6. 품질과 배포

- AI 평가 세트
- 보안 점검
- E2E 테스트
- 배포 문서와 사용자 가이드
