# 오류 및 안내 메시지 원칙

- 오류 원인과 사용자가 취할 행동을 함께 설명한다.
- 공급자 이름이나 내부 예외 메시지를 그대로 노출하지 않는다.
- 사용자가 작성한 입력은 생성 실패 후에도 유지한다.

| 상황 | 메시지 예시 |
|---|---|
| 필수 입력 누락 | 가게의 대표 상품을 한 개 이상 입력해 주세요. |
| AI 요청 시간 초과 | 생성 시간이 길어지고 있습니다. 잠시 후 다시 시도해 주세요. |
| 사용량 제한 | 현재 생성 요청이 많습니다. 잠시 후 다시 시도해 주세요. |
| 저장 실패 | 결과를 저장하지 못했습니다. 입력은 유지되어 있습니다. |
