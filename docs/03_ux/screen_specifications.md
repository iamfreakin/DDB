# 화면 명세

- 상태: Review
- 대상: 데스크톱 우선 반응형 웹

## 공통 레이아웃

- 흑백을 기본으로 하고 상태 안내에만 제한적으로 보조색을 사용한다.
- 넓은 여백, 얇은 구분선, 낮은 모서리 곡률로 편집 도구 같은 인상을 유지한다.
- 좌측: 서비스명, 가게 선택, 접힌 연결 및 AI 설정
- 상단: 현재 가게명, 업종, 프로필 버전, 브랜드 분위기
- 본문 상단: 브랜드 분석, 캠페인·콘텐츠, 가게 프로필 단계 전환
- 캠페인 내부: 콘텐츠, 전략, 캘린더, 새 캠페인 전환
- 생성 작업 중에는 진행 상태와 취소 또는 재시도 안내를 표시한다.

## 렌더링 원칙

- 현재 선택한 작업 단계만 API를 호출하고 화면을 렌더링한다.
- 캠페인의 게시물 8개는 목록으로 선택하고 한 번에 한 게시물의 상세만 렌더링한다.
- 변형 선택, 추가 생성, 포스터 브리프 생성은 부분 재실행으로 처리한다.
- 연결 상태와 가게 목록은 짧게 캐시하되 생성·저장 결과는 즉시 반영한다.
- API 설정은 폼 제출 시에만 적용하여 입력 중 전체 화면 재실행을 막는다.

## S-01 홈

### 표시

- 큰 브랜드 메시지와 서비스 한 줄 설명
- `새로 시작하기` 버튼
- 최근 가게 및 캠페인
- 브랜드 분석, 캠페인, 콘텐츠의 3단계 서비스 설명
- 저장된 가게가 없을 때의 시작 안내

### 동작

- 새로 시작하면 가게 정보 화면으로 이동한다.
- 최근 항목을 선택하면 마지막 작업 단계로 이동한다.
- 홈페이지에서는 API 키와 개발 설정을 노출하지 않는다.

## S-02 가게 정보

### 필수 입력

| 필드 | 형식 | 검증 |
|---|---|---|
| 가게명 | 한 줄 텍스트 | 1~50자 |
| 업종 | 선택 + 직접 입력 | 한 개 필수 |
| 대표 상품·서비스 | 반복 입력 | 1~5개, 항목당 50자 |
| 주요 고객 | 여러 줄 텍스트 | 10~300자 |
| 가게 강점 | 여러 줄 텍스트 | 10~500자 |
| 원하는 분위기 | 최대 3개 선택 | 한 개 이상 |

### 선택 입력

- 지역: 시·군·구 또는 동 수준, 정확한 주소는 요구하지 않음
- 가격대: 저가, 중간, 고가, 직접 입력
- 기존 홍보 문구
- 피하고 싶은 표현
- 캠페인에 사용할 사실 정보: 가격, 기간, 혜택

### 동작

- `임시 저장`: 현재 입력을 저장한다.
- `브랜드 분석하기`: 검증 후 저장하고 분석 화면으로 이동한다.
- 새로고침 후에도 저장된 입력을 복구한다.

## S-03 브랜드 분석

### 표시

- 한 문장 브랜드 정의
- 핵심 고객과 고객 필요
- 가치 제안과 차별점
- 브랜드 보이스 3개
- 추천 키워드와 금지 표현
- 정보 부족 항목

### 동작

- 각 항목을 직접 수정한다.
- `다시 생성`: 수정 전 결과를 이력으로 남기고 새 결과를 생성한다.
- `분석 승인`: 승인 버전을 고정하고 캠페인 화면으로 이동한다.
- 가게 정보가 바뀌면 기존 승인이 오래된 분석임을 표시한다.

## S-04 캠페인 전략

### 입력

- 캠페인 목표: 정의된 5개 목표 중 하나
- 캠페인명: 자동 제안 후 수정 가능
- 시작일: 오늘 이후 날짜
- 기간: MVP에서는 4주 고정
- 게시 빈도: MVP에서는 주 2회 기본
- 강조할 상품: 등록 상품 중 한 개 이상
- 필수 사실 정보: 가격, 혜택, 행사 기간 등 선택 입력

### 출력

- 캠페인 핵심 메시지
- 주차별 목표
- 콘텐츠 기둥 3~4개
- 8개 게시물 주제
- 주의할 과장 또는 누락 위험

## S-05 콘텐츠 제작

### 표시

- 게시물 8개 선택 목록
- 현재 선택한 게시물 상세 카드
- 카드별 주차, 주제, 콘텐츠 유형, 상태
- 선택한 게시물의 문구 변형, CTA, 해시태그, 이미지 콘셉트

### 동작

- 한 게시물당 최대 3개 변형을 생성한다.
- 문구를 직접 수정하고 원본과 수정본을 구분해 저장한다.
- 2~3개 변형을 비교한다.
- 게시물을 승인, 초안, 보류 상태로 변경한다.
- 포스터 브리프를 열거나 Markdown으로 복사한다.

## S-06 포스터 브리프

### 표시

- 핵심 문구와 보조 문구
- 이미지 콘셉트
- 색상, 구도, 분위기
- 이미지 생성 프롬프트
- 제외 요소
- 권장 비율

### 동작

- 프롬프트를 수정하고 저장한다.
- 텍스트 브리프를 복사하거나 Markdown으로 내보낸다.
- 실제 이미지 생성 버튼은 후속 버전에서 활성화한다.

## S-07 콘텐츠 캘린더

### 표시

- 4주 달력 또는 목록 보기
- 게시 예정일, 주제, 상태, 연결 콘텐츠
- 생성되지 않았거나 보류된 콘텐츠 경고

### 동작

- 같은 기간 안에서 게시일을 변경한다.
- 콘텐츠 카드를 선택해 상세 화면으로 이동한다.
- CSV를 내보낸다.

## S-08 결과 보관함

### 필터

- 생성 유형
- 캠페인
- 상태
- 생성일

### 동작

- 결과 상세 조회
- 2~3개 선택 후 비교
- 콘텐츠 복제
- 수정본 저장
- 삭제 전 확인

## 공통 상태

| 상태 | 화면 처리 |
|---|---|
| Empty | 다음 행동을 설명하는 안내와 시작 버튼 |
| Loading | 작업 이름과 진행 중임을 표시 |
| Success | 저장 또는 생성 완료 알림 |
| Validation Error | 해당 필드 가까이에 수정 방법 표시 |
| API Error | 입력 유지, 재시도 버튼, 간단한 원인 |
| Stale | 이전 단계 변경으로 결과가 오래되었음을 경고 |
