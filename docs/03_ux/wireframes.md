## 브랜드 분석

```text
+--------------------------------------------------------------+
| 브랜드 분석                                      [다시 생성] |
+----------------------------+---------------------------------+
| 한 문장 정의                | 동네에서 편히 머무는 수제 디저트 |
| 주요 고객                   | 20~30대 지역 주민               |
| 가치 제안                   | 직접 만든 메뉴와 편안한 공간     |
| 브랜드 보이스               | 따뜻한 / 솔직한 / 친근한         |
| 추천 키워드                 | 동네카페, 수제, 여유              |

+----------------------------+---------------------------------+
| [직접 수정]                            [분석 승인 ->]          |
+--------------------------------------------------------------+
```
