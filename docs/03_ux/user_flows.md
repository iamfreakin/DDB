# 사용자 흐름

- 상태: Review
- 관련 문서: `screen_specifications.md`, `../01_product/mvp_definition.md`

## 최초 제작 흐름

```text
홈
-> 가게 정보 입력
-> 입력 검증
-> 가게 프로필 저장
-> 브랜드 분석 생성
-> 분석 결과 확인 및 수정
-> 브랜드 분석 승인
-> 캠페인 목표와 시작일 선택
-> 4주 홍보 전략 생성
-> 전략 확인
-> Instagram 게시물 8개 생성
-> 게시물별 포스터 브리프 생성
-> 4주 캘린더 자동 배치
-> 결과 저장
-> 캘린더 CSV 내보내기
```

## 결과 비교 흐름

```text
결과 보관함
-> 비교할 결과 선택
-> 2~3개 결과 비교
-> 생성 설정과 문구 확인
-> 하나를 채택하거나 수정
-> 수정본 저장
-> 캘린더에 연결
```

## 재방문 흐름

```text
홈
-> 최근 가게 열기
-> 저장된 브랜드 분석 확인
-> 새 캠페인 시작 또는 기존 캠페인 열기
-> 저장된 콘텐츠 수정·비교·내보내기
```

## 실패 복구 흐름

```text
생성 요청
-> 시간 초과 또는 API 실패
-> 기존 입력과 이전 결과 유지
-> 오류 원인과 재시도 안내
-> 동일 설정으로 다시 시도
```

## 단계 이동 규칙

- 가게 프로필 저장 전에는 브랜드 분석을 생성할 수 없다.
- 브랜드 분석 승인 전에는 캠페인을 생성할 수 없다.
- 캠페인 전략 생성 전에는 게시물 일괄 생성을 시작할 수 없다.
- 콘텐츠 캘린더는 저장된 게시물이 한 개 이상 있어야 생성할 수 있다.
- 이전 단계로 돌아가 수정할 수 있으나, 변경 영향 범위를 사용자에게 알린다.
