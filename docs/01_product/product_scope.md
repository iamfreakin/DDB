# 제품 범위

- 상태: Review
- 기준 버전: MVP v0.1
- 관련 문서: `mvp_definition.md`, `../03_ux/user_flows.md`

## MVP 한 줄 정의

한 가게의 정보를 브랜드 프로필로 정리하고, 4주 홍보 전략과 Instagram 게시물
초안, 포스터 브리프, 실제 광고 포스터를 생성하여 저장·비교하는 단일 사용자 웹
서비스다.

## MVP 포함

- 로그인 없는 단일 사용자 환경
- 가게 한 곳의 기본정보 입력 및 수정
- 브랜드 분석 보고서 생성, 사용자 수정 및 승인
- 캠페인 목표 하나와 4주 기간 설정
- Instagram 피드 게시물 초안 생성
- 게시물당 최대 3개 문구 변형 생성
- 4주 콘텐츠 캘린더 생성
- 생성 결과 저장, 조회, 수정, 비교
- 이미지 생성용 포스터 브리프와 프롬프트 생성
- 이미지 API 또는 Mock 공급자를 이용한 포스터 배경 생성
- 정확한 한글 제목·보조 문구 합성, 미리보기, 재생성, 다운로드, 승인
- 브랜드 분석 보고서 Markdown 내보내기
- 콘텐츠 캘린더 CSV 내보내기

## 후속 확장

- 로고 업로드와 브랜드 템플릿을 이용한 고급 포스터 편집
- Instagram 외 블로그, 문자, 카카오채널 등 채널 확장
- 게시물 예약 발행
- 채널별 성과 데이터 연동
- 여러 매장 및 팀 협업
- 템플릿 마켓

## 제외

- 광고비 자동 집행
- 실제 매출 상승 보장
- 무검토 자동 게시
- 상표권 및 저작권에 대한 법률 판단
- 로그인, 결제, 권한 관리
- 외부 SNS 계정 직접 연동

## MVP 제약

- 브랜드 분석은 사용자가 입력한 정보만 근거로 한다.
- 외부 이미지 API는 사용자가 명시적으로 생성 버튼을 누르고 비용을 확인한 경우만 호출한다.
- 외부 최신 정보, 경쟁사 정보, 지역 상권 정보는 자동 수집하지 않는다.
- 날짜가 필요한 경우 사용자가 지정한 캠페인 시작일을 기준으로 한다.
