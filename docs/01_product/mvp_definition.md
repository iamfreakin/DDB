# MVP 정의

- 상태: Review
- 목적: 첫 번째 구현과 시연에서 반드시 완성할 사용자 경험을 고정한다.

## 대표 시나리오

카페 운영자가 가게와 대표 메뉴 정보를 입력한다. 시스템은 브랜드 분석을
생성하고, 운영자가 이를 확인·수정한다. 운영자는 `신메뉴 홍보` 목표와 캠페인
시작일을 선택한다. 시스템은 4주 전략, Instagram 게시물 초안, 포스터 브리프,
주 2회 콘텐츠 캘린더를 생성한다. 운영자는 여러 문구를 비교해 하나를 수정하고
저장한 뒤 캘린더를 CSV로 내보낸다.

## 사용자 가정

- 사용자는 한 번에 가게 한 곳을 관리한다.
- 사용자는 마케팅 전문용어를 잘 모를 수 있다.
- 사용자는 AI 결과를 검토하고 수정한 뒤 사용한다.
- 데스크톱 브라우저 사용을 우선하되 모바일에서도 내용을 읽을 수 있어야 한다.

## 고정 기본값

| 항목 | 기본값 |
|---|---|
| 기본 채널 | Instagram 피드 |
| 캠페인 기간 | 4주 |
| 게시 빈도 | 주 2회 |
| 문구 변형 수 | 3개 |
| 게시물 길이 | 보통 |
| 이모지 | 적당히 사용 |
| 해시태그 | 5~10개 |
| 콘텐츠 상태 | 초안 |

## 캠페인 목표

MVP에서는 다음 중 하나를 선택한다.

- 신메뉴 또는 신상품 홍보
- 신규 고객 방문 유도
- 재방문 유도
- 시즌 또는 행사 홍보
- 브랜드 인지도 향상

## 완료 정의

다음 조건을 모두 만족하면 MVP 핵심 흐름이 완료된 것으로 본다.

1. 가게 프로필을 저장할 수 있다.
2. 브랜드 분석을 생성하고 사용자가 승인할 수 있다.
3. 캠페인 전략과 게시물 8개를 생성할 수 있다.
4. 게시물별 포스터 브리프를 확인할 수 있다.
5. 게시물 변형을 비교하고 수정본을 저장할 수 있다.
6. 4주 캘린더를 생성하고 CSV로 내보낼 수 있다.
