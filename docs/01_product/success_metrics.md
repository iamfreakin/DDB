# 성공 지표

## 제품 지표

- 첫 브랜드 프로필 완성률
- 첫 콘텐츠 생성 완료율
- 저장된 결과의 재사용률
- 사용자 수정 후 채택된 생성 결과 비율
- 콘텐츠 캘린더 생성 완료율

## 품질 지표

- 금지 표현 위반률
- 브랜드 보이스 준수 점수
- 필수 정보 누락률
- 생성 실패율과 평균 응답 시간

## MVP 목표값

| 지표 | 목표 |
|---|---|
| 핵심 흐름 완료율 | 테스트 사용자 80% 이상 |
| 첫 결과 생성까지 걸리는 시간 | 10분 이내 |
| 생성 결과 구조 검증 성공률 | 95% 이상 |
| 입력에 없는 사실 생성률 | 평가 세트 기준 5% 미만 |
| 외부 API 제외 화면 응답 시간 | 2초 이내 |
| 텍스트 생성 요청 성공률 | 정상 환경에서 95% 이상 |

초기 목표값이며 최소 5명의 사용자 테스트 결과를 바탕으로 재검토한다.
