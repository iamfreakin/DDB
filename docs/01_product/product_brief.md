# 제품 개요

- 상태: Draft
- 목적: 제품을 한 페이지 수준으로 설명한다.

## 문제

소상공인은 홍보 콘텐츠가 필요하지만 브랜드 전략, 카피라이팅, 디자인에 사용할
시간과 비용이 부족하다. 생성형 AI를 개별적으로 사용하면 결과의 일관성을
유지하기 어렵고 과거 결과를 관리하기도 어렵다.

## 제안

가게 정보를 브랜드 프로필로 구조화하고, 이를 모든 콘텐츠 생성의 공통 기준으로
사용하는 AI 콘텐츠 제작 웹 서비스를 제공한다.

## 핵심 사용자

- 직접 SNS를 운영하는 1인 사업자
- 마케팅 담당자가 없는 소규모 매장 운영자
- 여러 매장의 콘텐츠를 관리하는 소규모 대행자

## 핵심 가치

- 무엇을 홍보할지 결정하는 시간을 줄인다.
- 채널별 게시물 초안을 빠르게 만든다.
- 여러 결과를 비교하고 재사용한다.
- 브랜드 말투와 핵심 메시지의 일관성을 높인다.
