# 사용자 페르소나

## P1. 1인 카페 운영자

- 목표: 신메뉴와 매장 분위기를 꾸준히 알리고 싶다.
- 어려움: 사진은 있지만 문구 작성과 게시 계획이 어렵다.
- 성공 기준: 20분 안에 일주일치 게시물 초안을 만든다.

## P2. 지역 서비스업 운영자

- 목표: 신뢰감을 주는 정보형 콘텐츠를 만들고 싶다.
- 어려움: 과장 광고를 피하면서 차별점을 설명하기 어렵다.
- 성공 기준: 브랜드 말투가 일관된 콘텐츠를 반복 생성한다.

## P3. 소규모 마케팅 대행자

- 목표: 여러 가게의 콘텐츠를 빠르게 제작하고 비교하고 싶다.
- 어려움: 고객별 설정과 결과 파일이 흩어진다.
- 성공 기준: 가게별 브랜드 프로필과 생성 이력을 분리 관리한다.
