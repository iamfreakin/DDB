# 기능 요구사항

- 상태: Review
- 범위: MVP v0.1

| ID | 기능 | 우선순위 |
|---|---|---|
| FR-101 | 사용자는 가게 기본정보를 입력하고 수정할 수 있다 | Must |
| FR-102 | 시스템은 입력 정보로 브랜드 분석을 생성한다 | Must |
| FR-103 | 사용자는 생성된 브랜드 분석을 수정하고 승인할 수 있다 | Must |
| FR-104 | 사용자는 홍보 목표, 시작일, 강조 상품을 설정할 수 있다 | Must |
| FR-105 | 시스템은 승인된 브랜드 분석과 캠페인 설정으로 4주 홍보 전략을 생성한다 | Must |
| FR-106 | 시스템은 전략을 바탕으로 Instagram 게시물 8개를 생성한다 | Must |
| FR-107 | 사용자는 게시물별 최대 3개의 문구 변형을 생성할 수 있다 | Must |
| FR-108 | 시스템은 게시물별 이미지 생성 프롬프트와 포스터 브리프를 만든다 | Must |
| FR-109 | 시스템은 게시물을 4주 콘텐츠 캘린더에 배치한다 | Must |
| FR-110 | 사용자는 생성 결과를 수정하고 원본과 구분해 저장할 수 있다 | Must |
| FR-111 | 사용자는 저장한 결과를 다시 조회할 수 있다 | Must |
| FR-112 | 사용자는 2~3개 콘텐츠 결과를 나란히 비교할 수 있다 | Should |
| FR-113 | 사용자는 브랜드 보고서를 Markdown으로 내보낼 수 있다 | Should |
| FR-114 | 사용자는 콘텐츠 캘린더를 CSV로 내보낼 수 있다 | Should |
| FR-115 | 시스템은 생성 실패 시 입력을 유지하고 재시도를 제공한다 | Must |
| FR-116 | 시스템은 이전 단계 변경으로 오래된 결과를 식별한다 | Should |
| FR-117 | 시스템은 후속 이미지 생성 API 결과를 저장할 수 있다 | Could |

## 우선순위 정의

- Must: MVP 핵심 흐름에 필수
- Should: MVP 시연 완성도를 높이며 일정이 허용하면 포함
- Could: 후속 확장 대비 설계만 반영
