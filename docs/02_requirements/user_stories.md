# 사용자 스토리

| ID | 사용자 스토리 |
|---|---|
| US-101 | 가게 운영자로서, 브랜드에 맞는 콘텐츠를 만들기 위해 가게 정보를 등록하고 싶다 |
| US-102 | 가게 운영자로서, 강점과 고객층을 이해하기 위해 브랜드 분석을 보고 싶다 |
| US-103 | 가게 운영자로서, 홍보 방향을 정하기 위해 목표별 전략을 추천받고 싶다 |
| US-104 | 가게 운영자로서, 게시 준비 시간을 줄이기 위해 SNS 문구를 여러 버전으로 만들고 싶다 |
| US-105 | 가게 운영자로서, 꾸준히 게시하기 위해 콘텐츠 캘린더를 만들고 싶다 |
| US-106 | 가게 운영자로서, 더 좋은 문구를 고르기 위해 결과를 비교하고 싶다 |
| US-107 | 가게 운영자로서, AI 결과를 그대로 쓰지 않고 직접 수정한 뒤 저장하고 싶다 |
| US-108 | 가게 운영자로서, 디자인 제작에 활용하기 위해 포스터 브리프를 받고 싶다 |
| US-109 | 가게 운영자로서, 실패 후 내용을 다시 쓰지 않도록 입력이 유지되길 원한다 |
| US-110 | 가게 운영자로서, 결과를 다른 도구에서도 쓰기 위해 파일로 내보내고 싶다 |
