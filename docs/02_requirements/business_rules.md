# 비즈니스 규칙

- 브랜드 분석이 없으면 콘텐츠 생성 전에 분석 생성을 안내한다.
- 모든 콘텐츠 생성은 특정 브랜드 프로필 버전을 참조한다.
- 가격, 할인율, 기간 등 사실 정보는 사용자 입력값만 사용한다.
- 입력되지 않은 영업시간, 주소, 효능을 임의로 만들어내지 않는다.
- 사용자가 수정한 최종본과 AI 원본을 구분해 저장한다.
- 가게를 삭제하면 연결된 분석, 캠페인, 콘텐츠, 캘린더도 함께 삭제하되 확인
  절차를 거친다.
- 브랜드 프로필을 수정해도 이전 버전은 생성 결과 추적을 위해 유지한다.
- 승인된 분석의 기반 프로필이 수정되면 분석과 하위 결과를 오래된 상태로 표시한다.
