| ID | 영역 | 요구사항 |
|---|---|---|
| NFR-201 | 사용성 | 처음 사용하는 사용자가 별도 교육 없이 핵심 흐름을 완료해야 한다 |
| NFR-202 | 성능 | 외부 AI 호출을 제외한 일반 화면 요청은 로컬 기준 2초 이내를 목표로 한다 |

| NFR-207 | 추적성 | 생성 결과에 사용한 브랜드 프로필과 설정을 추적할 수 있어야 한다 |

| NFR-209 | 유지보수성 | UI, 도메인, AI 공급자 코드를 분리한다 |
| NFR-210 | 호환성 | 최신 Chrome 및 Edge 데스크톱 환경에서 핵심 흐름이 동작해야 한다 |
| NFR-211 | 데이터 | Markdown 및 CSV 내보내기는 UTF-8로 생성한다 |
