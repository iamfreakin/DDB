# 인수 기준

- 상태: Review

## AC-101 가게 프로필

- 가게명, 업종, 대표 상품, 주요 고객, 강점, 분위기를 필수로 검증한다.
- 오류는 해당 필드 가까이에 수정 방법과 함께 표시한다.
- 저장 후 페이지를 다시 열어도 값이 유지된다.
- 선택 정보가 비어 있어도 필수 정보가 유효하면 저장할 수 있다.

## AC-102 브랜드 분석

- 분석 결과는 브랜드 정의, 고객, 가치, 차별점, 보이스, 키워드, 금지 표현,
  정보 부족 항목을 포함한다.
- 결과는 구조화된 필드로 저장한다.
- 사용자는 각 필드를 수정할 수 있다.
- 승인한 분석에는 승인 상태와 참조 프로필 버전을 기록한다.

## AC-103 캠페인 전략

- 캠페인 목표는 정의된 5개 중 하나를 선택한다.
- 시작일, 강조 상품, 캠페인명이 저장된다.
- 전략은 핵심 메시지, 주차별 목표, 콘텐츠 기둥, 게시물 주제 8개를 포함한다.
- 승인된 브랜드 분석이 없으면 전략 생성을 시작하지 않는다.

## AC-104 SNS 콘텐츠

- 시스템은 캠페인당 Instagram 게시물 8개를 생성한다.
- 각 결과는 첫 문장, 본문, CTA, 해시태그, 이미지 콘셉트, 핵심 메시지를 포함한다.
- 한 게시물에서 최대 3개 변형을 생성할 수 있다.
- 변형은 단순 단어 교체가 아니라 문체 또는 접근 방식이 구분되어야 한다.
- 입력에 없는 가격, 할인, 효능, 인증 정보를 사실처럼 포함하지 않는다.

## AC-105 포스터 브리프

- 각 게시물은 핵심 문구, 보조 문구, 분위기, 색상, 레이아웃, 이미지 프롬프트,
  제외 요소, 비율을 포함하는 브리프를 가진다.
- 사용자는 프롬프트를 수정하고 저장할 수 있다.
- 실제 이미지 API가 없어도 브리프 생성 기능은 동작한다.

## AC-106 캘린더

- 기본 설정에서 8개 게시물을 4주 동안 주 2회 배치한다.
- 모든 게시일은 캠페인 기간 안에 있어야 한다.
- 사용자는 기간 안에서 게시일을 변경할 수 있다.
- 캘린더 항목은 연결된 콘텐츠와 상태를 표시한다.

## AC-107 저장 및 조회

- AI 원본과 사용자 수정본을 별도 필드 또는 버전으로 구분한다.
- 저장한 브랜드, 캠페인, 콘텐츠를 다시 조회할 수 있다.
- 저장 실패 시 입력과 화면의 생성 결과를 유지한다.

## AC-108 비교

- 사용자는 같은 콘텐츠의 결과 2~3개를 선택할 수 있다.
- 비교 화면은 생성 설정, 첫 문장, 본문, CTA, 해시태그를 나란히 표시한다.
- 비교한 결과 중 하나를 선택해 수정본으로 저장할 수 있다.

## AC-109 내보내기

- 브랜드 분석은 UTF-8 Markdown 파일로 내보낸다.
- 캘린더는 날짜, 채널, 유형, 주제, 핵심 메시지, 상태를 포함한 UTF-8 CSV로
  내보낸다.
- 내보내기 파일명에는 가게명과 생성일을 포함한다.

## AC-110 실패 복구와 변경 영향

- AI 요청 실패 시 사용자가 입력한 값과 이전 성공 결과를 유지한다.
- 같은 설정으로 다시 시도할 수 있다.
- 승인된 브랜드 분석의 기반 정보가 변경되면 해당 분석을 `오래됨`으로 표시한다.
- 오래된 분석을 참조한 전략과 콘텐츠에도 경고를 표시한다.
