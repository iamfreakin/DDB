# Frontend

FastAPI 백엔드를 호출하는 Streamlit 웹 UI다. 가게 프로필부터 캠페인, 콘텐츠,
포스터 브리프, 캘린더까지 MVP 흐름을 다룬다.

## 실행

먼저 백엔드를 실행한다.

```powershell
.\scripts\run_backend.cmd
```

그다음 프론트엔드를 실행한다.

```powershell
.\scripts\run_frontend.cmd
```

브라우저에서 `http://localhost:8501`이 자동으로 열린다.

## 의존성 설치 (최초 1회)

```powershell
python -m pip install -r frontend/requirements.txt
```

## 설정

- 백엔드 주소는 사이드바에서 바꾸거나 환경변수 `BACKEND_URL`로 지정한다.
- 기본값은 `http://localhost:8000`이다.
- OpenAI API 키는 사이드바에서 선택 입력한다.
- 키를 입력하지 않으면 Mock 생성기로 동작한다.
- 키는 저장하지 않고 생성 요청 헤더로만 전달한다.

## 현재 화면 범위

- 백엔드 연결 상태 확인
- 가게 생성, 목록, 선택
- 브랜드 프로필 입력과 새 버전 생성
- AI 브랜드 분석 생성, 수정, 승인
- 캠페인 생성
- 전략 생성
- Instagram 게시물 8개 생성
- 게시물 변형 선택과 추가 변형 생성
- 포스터 브리프 생성
- 콘텐츠 캘린더 생성
- 결과 비교와 다운로드 링크

## UI와 실행 성능

- 흑백 중심의 편집 도구 스타일과 넓은 여백을 사용한다.
- 브랜드 단계와 캠페인 단계를 단일 선택 탐색으로 분리한다.
- Streamlit 탭의 전체 실행을 피하고 현재 선택한 화면만 렌더링한다.
- 게시물 8개 중 선택한 한 개의 상세만 화면에 그린다.
- 변형 선택, 추가 생성, 포스터 브리프 생성은 부분 재실행한다.
- 백엔드 HTTP 연결을 재사용한다.
- API 키는 브랜드 조회나 변형 선택 요청에 포함하지 않고 AI 생성 요청에만 전달한다.
