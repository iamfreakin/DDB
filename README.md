# AI 소상공인 콘텐츠 제작실

가게 정보를 입력하면 브랜드를 분석하고, 홍보 전략과 SNS 콘텐츠를 생성하며,
향후 이미지 생성 API를 통해 광고 포스터까지 제작하는 웹 기반 AI 서비스입니다.

## 핵심 흐름

```text
가게 정보 입력
-> 브랜드 분석
-> 홍보 전략 추천
-> SNS 게시물 생성
-> 광고 포스터 생성
-> 콘텐츠 캘린더 작성
-> 결과물 저장 및 비교
```

## 현재 단계

FastAPI와 SQLite 기반의 백엔드 첫 수직 흐름을 구현했습니다. 현재 가게 프로필
생성, 버전 관리, Mock AI 브랜드 분석, 수정 및 승인이 동작합니다.

상세 문서는 [`docs/README.md`](docs/README.md), 실행 방법은
[`backend/README.md`](backend/README.md)에서 확인할 수 있습니다.

## 문서화 원칙

- 프로젝트의 결정 사항은 관련 문서에 기록합니다.
- 한 문서는 하나의 주요 책임만 다룹니다.
- 요구사항에는 식별자를 부여해 설계 및 테스트와 연결합니다.
- 확정되지 않은 내용은 사실처럼 기록하지 않고 `TBD`로 표시합니다.
- 구현 변경으로 문서와 코드가 달라지면 같은 작업에서 함께 수정합니다.
